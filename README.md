# 📚 AI Book Recommender

A web app that suggests books you might like using AI.

## What is this?

This app helps you discover new books by analyzing what you like and finding similar books.

## How to Run

1. **Install Python** (if you don't have it)
   - Download from python.org

2. **Install packages**
   ```bash
   pip install -r requirements.txt
   ```

3. **Start the app**
   ```bash
   python app.py
   ```

4. **Open browser**
   - Go to: `http://localhost:5000`

That's it! 

## What You Can Do

- Search for books
- Get book recommendations
- Save books to your reading list
- Compare different recommendation methods

## Files

- `app.py` - Main application file (run this!)
- `data/` - Book data
- `templates/` - Web pages
- `requirements.txt` - List of needed packages

## Need Help?

Just run `python app.py` and visit `http://localhost:5000` in your browser.
