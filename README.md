# 📚 AI Book Recommendation System

A smart web application that recommends books using multiple AI algorithms. Find your next favorite read!

## ✨ Features

- **Multiple Recommendation Algorithms**: Choose from different AI methods
  - Content-based recommendations (LSA)
  - Collaborative filtering
  - Hybrid approach
  - Deep learning models
- **Web Interface**: Easy-to-use Flask web app
- **Book Search**: Search through thousands of books
- **Reading Lists**: Save books you want to read
- **System Comparison**: Compare different recommendation methods

## 🚀 Quick Start

### Prerequisites

- Python 3.8 or higher
- pip (Python package manager)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/ongcw11/library-ai-recommender.git
   cd library-ai-recommender
   ```

2. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the application**
   ```bash
   python app.py
   ```

4. **Open your browser**
   - Go to `http://localhost:5000`
   - Start exploring book recommendations!

## 📖 How to Use

1. **Get Recommendations**: Enter a book title or author to get personalized recommendations
2. **Browse Books**: Search and explore the book database
3. **Save Books**: Add books to your reading list
4. **Compare Systems**: See how different AI algorithms perform

## 🗂️ Project Structure

```
├── app.py                          # Main Flask application
├── data/                           # Book data files
├── templates/                      # HTML templates
├── model_cache/                    # Cached AI models
├── requirements.txt                # Python dependencies
└── [recommender modules]          # Different recommendation algorithms
```

## 🔧 Technologies Used

- **Flask** - Web framework
- **Pandas & NumPy** - Data processing
- **Scikit-learn** - Machine learning
- **PyTorch & TensorFlow** - Deep learning
- **Gensim** - Topic modeling (LSA)
